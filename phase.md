# Roadmap: Transition to African Press Agency Leader

This document breaks down the implementation phases to transform the current application into a premier press destination for CSR and ESG in Africa, including the necessary Administrative (CRUD) updates.

## Phase 1: Editorial UI & Identity (The "Press" Look)
*Objective: Establish immediate professional credibility.*
- [ ] **Navigation Refactoring**: Add "Sectors" to the main nav (CSR, ESG, Energy, Leaders, Reports).
- [ ] **Breaking News Ticker**: Implement a smooth scrolling ticker for real-time sustainability headlines.
- [ ] **Admin Update**: Add "Breaking News" CRUD to the dashboard to manage the ticker content.
- [ ] **Hero Press Grid**: Replace carousel with a static, dense 1+4 article grid.
- [ ] **Color Overhaul**: Switch to a more authoritative, high-contrast palette.

## Phase 2: Category & Content Depth
*Objective: Organize content for the professional reader.*
- [ ] **Sector-Specific News Feeds**: Category-filtered landing pages (e.g., /news/finance).
- [ ] **Admin Update**: Expand News CRUD to include a robust "Sector/Category" manager.
- [ ] **Enhanced Metadata**: Add "Reading Time," "Author Bio," and "Sector Tags" on article previews.
- [ ] **Premium Tiers**: Add a "Premium/Exclusive" flag to news items.
- [ ] **Admin Update**: Toggle "Premium" status in the News Editor.

## Phase 3: Engagement & Retention
*Objective: Capture and grow the audience.*
- [ ] **Newsletter Pop-up System**: Implement a non-intrusive popup for email capture.
- [ ] **"In Kiosk" Monthly Review Widget**: A sidebar section showing the cover of the monthly PDF review.
- [ ] **Admin Update**: CRUD for "Monthly Reviews" (PDF upload, cover image, and publication date).
- [ ] **Member Portal v1**: Simple registration for "Saving" articles and managing email alerts.

## Phase 4: Multimedia & Integration
*Objective: Become a holistic resource.*
- [ ] **FA TV / Podcast Sidebar**: Integrated multimedia player for interviews and audio analysis.
- [ ] **Admin Update**: CRUD for Multimedia feeds (Embed links for YouTube/Spotify/Podbean).
- [ ] **Search & Archive**: Advanced search with date filters and sectoral keywords.
- [ ] **Newsletter Segmentation**: Back-end support for "ESG-only" or "Energy-only" newsletters.

## Phase 5: Monetization Framework (Preparing for Scale)
*Objective: Set the stage for paid access.*
- [ ] **Subscription Plans UI**: A "Join Pro" pricing page mock / implementation.
- [ ] **Admin Update**: Subscription management dashboard (User status, payments, access logs).
- [ ] **Fragmented Gating**: Preview logic (e.g., first 3 paragraphs free, then CTA).
- [ ] **Partner Ad Spaces**: Strategically placed, non-intrusive banners for sponsors.
- [ ] **Admin Update**: Ad Manager (Upload banners, set display rules, track impressions).
